# fake-news-detective-hackathon2026

Hackathon 2026, Semicolon squad: Caroline Fagner, Christine Blomstrand och Therese Lindberg

## Beskrivning

Fake News Detective är en React-baserad webapp där spelaren får träna på att identifiera fake news och utveckla sitt kritiska tänkande kring information på internet.

Spelaren får läsa artiklar och analysera innehållet för att hitta olika typer av misstänkta detaljer och varningssignaler. Genom att göra korrekta fynd samlar spelaren poäng, levlar upp och låser upp svårare nivåer.

## Funktioner

- Läs och analysera artiklar
- Identifiera misstänkta detaljer och “fynd”
- Poängsystem baserat på korrekta analyser
- Level-system med ökande svårighetsgrad
- Responsiv design för webbläsare

## Exempel på fynd

Spelaren kan få poäng genom att upptäcka:

- Märkliga eller falska URL:er
- Bilder som inte passar artikeln
- Obekräftad forskning
- Klickbeten och överdrivna rubriker
- Saknade eller opålitliga källor
- Manipulerad statistik
- AI-genererade eller redigerade bilder

## Syfte

Projektets mål är att:

- Öka medvetenheten kring desinformation
- Lära användare att tänka källkritiskt
- Träna spelare i att granska information innan den delas eller tros på

## Installation

Klona projektet:

```bash
git clone <repository-url>
```

Gå till projektmappen:

```bash
cd kallkritiksspelet
```

Installera dependencies:

```bash
npm install
```

Starta utvecklingsservern:

```bash
npm run dev
```
